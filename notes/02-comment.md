# 02 注释 comment

只写代码看不出来的东西: 为什么 边界 坑. 不复述代码.

## 文件头

每个 .py 开头 3-5 行:

```
"""
<模块一句话>.

职责: <做什么>.
边界: <不做什么>.
"""
```

- 一句话说清是什么, 不列"主要特性 1. 2. 3."
- 空一行再写职责边界, 没有边界就不写

## 函数 docstring

- 第一行: 动词加对象, 不写"本函数用于"
- 3 步以上写 业务逻辑: 1. 2. 3.
- Args Returns Raises 只写真实存在的; 参数名后冒号, 不写类型, 类型在签名里
- 私有小函数一句话即可

骨架:

```
"""
校验 pdf 路径并确保输出目录可用.

业务逻辑:
    1. 从 state 取 pdf_path 与 local_file_dir
    2. 校验 pdf_path 并转 Path
    3. 校验文件存在, 目录不存在则创建

Args:
    state: 图全局状态.

Returns:
    tuple[Path, Path]: pdf 文件与输出目录.

Raises:
    ValueError: pdf_path 非法.
    FileNotFoundError: pdf 文件不存在.
"""
```

## 代码内注释

- 与 docstring 步骤一一对应: `# 1. 取 pdf_path`
- 行内注释只写原因: `# 关闭思考链, 降低延迟`
- 分区线固定 75 个短横线, 整行 77 字符, 分区名 2-4 字: 依赖导入 常量 主流程 内部方法
- 每个文件 2-4 个分区, 小文件不分区

## 副作用

- 改 state 写文件 建目录 上传对象的函数, docstring 补一段:

```
副作用:
    回写 state["md_content"].
```

- 一次只写一个持久字段, 字段名必须与 state 定义一致
- 纯替换正文 生成 URL 这类无副作用函数不写

## 不写

- 注释掉的代码, 直接删, git 有历史
- 修改记录 作者 日期
- "初始化变量" "循环遍历" 这类废话
- 不带原因的 TODO; 写法: `# TODO: 待实现, 需要 MinIO 凭证`

## 风格

- 中文为主, 英文术语保留: 读取 state 中的 md_path
- 中英文之间留空格
- 括号用 ASCII, 不用全角括号
- 一行不超过 100 字符
- 短注释不加句号, 完整句子加句号
